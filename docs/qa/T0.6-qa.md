### Observations (no defect)

- `formatPkr(locale, rupees: number)` (`packages/i18n/src/money.ts`) accepts whole rupees only. T2.3 stores money as BigInt **paisa** (`*Minor`). T1.4 should add a minor-units/BigInt formatter so that screens never divide by 100 by hand. Open format question: OQ-079.
- After the language toggle, the flow asserts only that `urdu-smoke-paragraph` is visible. It does not check that the language changed. The screenshots `en-01-top` and `ur-01-top` cover this, so it is fine for a smoke flow.
- `pnpm-lock.yaml` and `pnpm-workspace.yaml` also contain the T2.3 Prisma changes. Both tasks must be committed together, or the frozen install fails.
