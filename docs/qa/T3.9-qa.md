## 1. Verbatim Acceptance Criteria Verification (IMPL §6 T3.9)

> **Verbatim Acceptance Criteria:**
> *"Permissions only requested on tap; every input has a fallback (AI down → C12 simple form; mic denied → typing; camera denied → gallery; GPS denied → manual address); zero hardcoded user-facing strings in JSX."*

| Criteria | Implementation & Evidence | Verification | Result |
|---|---|---|---|
| **Permissions only requested on tap** | Dangerous permissions (`location`, `microphone`, `camera`) are **never** requested on screen load, mount, or transition. In `C39` (location), permission is prompted only when tapping "Use current location" (`c39-use-gps-button`). In `C32` (audio note), permission is prompted only when tapping the record button (`c32-record-button`). In `C33` (video), permission is prompted only when tapping "Grant camera access" (`c33-grant-camera-button`) or recording trigger. Every permission is preceded by an in-context educational rationale modal (`PermissionModal`; `PERM-JUST-001..003`) explaining why Kaam Karo needs the permission before triggering OS prompts. | Verified in `apps/customer/src/intake-flow.spec.ts` (test: `permissions are never prompted on screen mount; rationale modal shown on explicit tap`). | **PASS** |
| **Every input has a fallback** | 1. **AI down / low confidence → C12 Simple Form:** `C31` includes an explicit fallback banner & button ("Switch to standard form", `c31-fallback-simple-form`) routing directly to `C12`. If AI service is unavailable or confidence is low, users seamlessly switch to structured form.<br>2. **Mic denied → Typing:** If microphone permission is denied, `C32` displays a prominent warning box with an immediate action "Type your request instead" (`c32-fallback-typing`) routing back to `C31` with the text input focused.<br>3. **Camera denied → Gallery:** If camera permission is denied, `C33` displays a clear notice with "Select from gallery" (`c33-fallback-gallery`) allowing direct file picker attachment.<br>4. **GPS denied → Manual address:** If GPS/location permission is denied, `C39` displays a manual address entry section (`c39-manual-address-input`, `c39-save-manual-address-button`) and saved addresses list (`c39-saved-address-0`), allowing address selection without GPS coordinates. | Verified in `apps/customer/src/intake-flow.spec.ts` (tests: `C31 provides fallback to C12 Simple Form`, `C32 audio recorder handles mic permission denial with typing fallback`, `C33 video recorder handles camera permission denial with gallery fallback`, `C39 location confirm provides manual address fallback when location permission is denied`). | **PASS** |
| **Zero hardcoded user-facing strings in JSX** | All text, labels, button titles, placeholders, hints, and error messages in `C12`, `C31`, `C32`, `C33`, `C34`, `C39`, and `PermissionModal` are resolved via `translate(locale, key, params)` using synchronized keys in `@kaamkaro/i18n`. All duration strings use parameterized format `{title} ({seconds}s)`. | `guard:string-lint` scanned all 32 UI files and confirmed: `Passed: 32 UI file(s) checked (0 hard-coded literals), message catalogs 100% synchronized.` | **PASS** |
