## 3. Verbatim Acceptance Criterion Verification Detail

- **Criterion:** *"Oversize/overlong media rejected; draft survives failure"* (IMPL §6 T3.2, BP §76).
- **Verification Result:**
  - Case 1 (Oversize): Finalizing a photo with `actualSizeBytes: 30_000_000` (> 25 MiB limit) throws `PayloadTooLargeException` (HTTP 413). Database record `uploadStatus` is updated to `FAILED`, preserving the record ID so the client draft is not destroyed.
  - Case 2 (Overlong): Finalizing a video with `durationMs: 45_000` (> 30s limit) throws `BadRequestException` (HTTP 400). Database record `uploadStatus` is updated to `FAILED`, preserving draft association.
