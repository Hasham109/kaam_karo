Delivered the Customer App Core Screens (BP §12, BP §78, ARCH §3.1; D-004):
1. **Target Screens (C01–C11 + C41):**
   - `C01`: Splash / App Start (brand, session check, automatic redirection).
   - `C02`: Welcome (value proposition, Log in, Register, Continue as guest, Language toggle).
   - `C03`: Login (+92 phone input, validation, zero-account-reveal flow).

   - `C07`: Search & Intake Entry (search query input with clear, voice search button, category quick filter chips, recent searches with clear).
   - `C08`: Search Results (segmented tabs for Services / Providers, category chips, service price model representations, provider cards with verification badge, rating, distance, jobs done).
   - `C09`: Category View (category header with Urdu/English title, subcategory tabs, service cards with price models, "Not sure? Describe it" CTA).
   - `C10`: Service Detail (service title, Urdu/English description, what is included vs excluded, pricing model [FIXED, FROM, INSPECTION_QUOTE], visit/inspection fee breakdown, reviews, "Book now" CTA).
   - `C11`: Provider Profile (business name, avatar, verification level badge [`BASIC`, `VERIFIED`, `BUSINESS_VERIFIED`], rating summary, completed jobs, bio, services offered, reviews, favorite button toggle).
   - `C41`: Language Selection (English vs اردو, immediate live RTL layout and text flip without app restart, persisted in context).
2. **Design Tokens & Accessibility:**
   - 48×48 dp minimum tap targets on all touchable elements (`minTapTargetStyle()`; A11Y-002).
   - Fully mirrored layouts in Urdu (`row-reverse`, `textAlign: right`, horizontally scaled directional icons, Noto Nastaliq Urdu typography with 2.5× line height ratio; BP §78.1, §78.2; I18N-001..004).
   - Five-state handling (`L`, `E`, `S`, `X`, `P`) via `StateView`.
   - Status indicators use color + icon + text, never color alone (A11Y-003).
   - All interactive controls have stable `testID` and non-empty `accessibilityLabel` (`interactiveProps()`; A11Y-004).
3. **Guest Mode & Privacy:**
   - Safe guest browsing across C06–C11 without authentication (D-004).
   - Mutations (booking, favoriting) preserve draft state and route to `C03` login with return parameters.
   - Zero permissions requested at install, splash, or onboarding (PERM-JUST-001..003).
