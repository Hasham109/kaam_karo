## How to use it (for consumer agents)
- `translate(locale, key, params)`, `formatPkr(locale, rupees)`, `isolateLtr(locale, text)` and `otherLocale(locale)` come from `@kaamkaro/i18n`. A new key must be added to both `EN_MESSAGES` and `UR_MESSAGES`, otherwise tsc fails.
- From `@kaamkaro/ui`:
  - `textTokens(locale, 'body'|'title'|'headline'|'label')` returns fontFamily / fontSize / lineHeight; spread it into a Text style.
  - `mirroring(textDirection(locale), I18nManager.isRTL)` returns the row / textAlign / iconScaleX to use.
  - `MIN_TAP_TARGET_DP` is the minHeight/minWidth for every pressable.
- Do not set `lineHeight` on a TextInput. Use `minHeight = lineHeight + padding`, because Android TextInput lineHeight affects cursor placement.
