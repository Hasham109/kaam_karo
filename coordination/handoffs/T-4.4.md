## 1. Scope & Accomplishments

Delivered partner structured quote builder covering screen **P24** and crew size acceptance flows (`BP §18, §58; BP §13 P24, P10; D-004, D-006, D-015, D-018, D-025, D-029; QUOTE-001..009, FARE-001..011, PROV-CREW-001..006`):

1. **All 9 Canonical Line Types (`BP §58.1`, `FARE-001..011`):**
   - Implemented in `apps/partner/src/screens/P24QuoteBuilderScreen.tsx`.
   - Charge line types: `Visit / call-out`, `Inspection / diagnosis`, `Labour / service`, `Tools / equipment`, `Consumables`, `Parts / new materials`, `Emergency / after-hours`, `Travel / distance`, `Discount`.
   - Platform fee strictly absent (`D-025`).
   - Tax is computed by server backend (`D-029`).

2. **Verbatim Acceptance Criteria Gates (`IMPL §6 line 484`):**
   - Validity date (`validUntil`) strictly required.
   - What is included (`inclusions`) strictly required.
   - What is not included (`exclusions`) strictly required.
   - Expected duration in hours (`expectedDurationHours > 0`) strictly required.
   - Crew size stepper (`crewSize >= 1`) strictly required.
   - Send Quote button is disabled until all requirements and at least one charge line are present.

3. **Crew Size Invariant & Instant Booking Integration (`D-004`, `D-018`, `PROV-CREW-005`):**
   - Prominent informational banner rendered in builder: *"The number of workers does not change the price."* (`کاریگروں کی تعداد سے قیمت نہیں بدلتی۔`).
   - Integrated with P10 Action Sheet on instant bookings.

4. **Commission Split on Labour Lines ONLY (`D-006`, `D-015`, `COMM-004`):**
   - Live totals preview: `Customer pays {total} · Commission {commission} · Your share {payout}`.
   - 30% commission strictly calculated on `LABOUR_SERVICE` lines, exempting parts, tools, consumables, and travel.

5. **Conditional Line Attributes:**
   - Tools line: reason required (`toolsReason`, `FARE-004`).
   - Inspection line: deductible toggle (`isDeductible`, `FARE-002`, `PRICE-003`).
   - Parts/materials line: materials class selector (`INCLUDED`, `NOT_INCLUDED`, `EXTRA_NEEDS_APPROVAL`, `PRICE-005`).

6. **Screen States & Accessibility:**
   - 5 canonical screen states (`loading`, `empty`, `success`, `error`, `pending`).
   - Touch accessibility: 48×48 dp minimum tap targets.
   - Small screen ≤ 360 dp responsive design.
   - Noto Nastaliq Urdu typography with 2.5× line-height factor.
   - Full RTL layout mirroring.
   - 100% synchronized message catalogs between `PARTNER_EN` and `PARTNER_UR`.
