## What I Built

### 1. OpenAPI Contract (`contracts/location.yaml`)
- Published contract for Location & Geocoding Service under OpenAPI 3.1.0 (semver 0.1.0).
- Registered in `contracts/README.md`.
- Endpoints defined:
  - `GET /v1/location/suggest`: Suggests location for guest/new user ("We think you are in Lahore", `canChangeCity: true`).
  - `GET /v1/location/autocomplete`: Searches addresses and landmarks with Lahore/Pakistan bias.
  - `POST /v1/location/geocode`: Resolves address text to coordinates.
  - `POST /v1/location/reverse-geocode`: Resolves coordinates to human-readable address.
  - `POST /v1/location/route`: Computes route distance (meters) and duration (seconds) with fallback flag.
  - `POST /v1/location/validate`: Validates coordinates are strictly inside Pakistan boundary and evaluates city launch active status.
- Validated by `@kaamkaro/contracts` schema tests (29/29 tests pass).

### 2. Pakistan Geographic Boundary & Bounding Box (`pakistan-boundary.ts`)
- Implemented `isInsidePakistan(coords)` and `assertInsidePakistan(coords)` enforcing strict mainland bounding box:
  - Latitude: [23.5, 37.2]° N
  - Longitude: [60.5, 78.0]° E
- Defined default reference center: `LAHORE_CENTER` (lat 31.5204, lng 74.3587).
- Rejects coordinates outside Pakistan with `OUT_OF_SERVICE_AREA` (HTTP 400).

### 3. Haversine Distance & Urban Travel Duration (`haversine.ts`)
- Mathematical Haversine formula (`calculateHaversineDistanceMeters`) using WGS84 mean earth radius (6,371,000 meters).
- Urban travel duration estimator (`estimateUrbanDurationSeconds`) using average Pakistani urban transit speed (25 km/h ~ 6.94 m/s) with a 3-minute (180s) buffer for local street navigation/traffic.

### 4. Google Maps Platform Server Client (`google-maps.client.ts`)
- Server-side proxy for Google Maps Platform APIs (Geocoding, Places Autocomplete, Routes API).
- Configurable via environment variables (`GOOGLE_MAPS_API_KEY`, `GOOGLE_MAPS_ENABLED`).
- Parameterless constructor for clean NestJS dependency injection, with `configure()` and `setEnabled()` methods for runtime toggling and testing.
- Fails closed when disabled or when quota is exceeded, triggering seamless fallback.
- **Security Control:** Keeps all Google Maps API keys server-side only; prevents client-side bundle leaks (`LOC-GEO-008`).

### 5. GeoService Core Engine (`geo.service.ts`)
- Full implementation of location features with graceful fallback:
  - `suggestLocation()`: Returns Lahore as default launch city with message "We think you are in Lahore", `canChangeCity: true`, and list of other Pakistan cities marked `isActive: false` (BP §57, D-007, D-019).
  - `autocomplete()`: Queries Google Maps Places API when enabled; falls back seamlessly to database catalog cities and local landmarks when disabled or offline.
  - `geocode()`: Resolves address via Google Maps Geocoding API when enabled; falls back to catalog city coordinates. Strictly asserts result is within Pakistan.
  - `reverseGeocode()`: Resolves coordinates via Google Maps when enabled; falls back to nearest city/locality check when disabled. Asserts coordinates inside Pakistan.
  - `computeRoute()`: Computes driving route via Google Maps Routes API when enabled; falls back to Haversine straight-line distance and urban transit formula with `isFallback: true` flag when disabled (LOC-GEO-005, LOC-GEO-006).
  - `validateLocation()`: Validates coordinate containment in Pakistan and active operational status in Lahore.

### 6. Controller & Module Registration (`location.controller.ts`, `location.module.ts`, `app.module.ts`)
- NestJS controller exposing endpoints under `/v1/location/*` with `@Public()` decorators for onboarding and guest browsing flows.
- Registered in `AppModule` and exported for consumption by Booking, Profiles, and Intake modules.

## Known Limitations & Upstream Assumptions
- Launch city is strictly Lahore (`D-007`). Other Pakistan cities (Karachi, Islamabad, Rawalpindi, Peshawar, Multan, Faisalabad, Quetta) are returned in suggestions for UI presentation but marked `isActive: false` until regional rollout phases.
- Real Google Maps API calls in production require `GOOGLE_MAPS_API_KEY` set in environment; without this key, the system runs safely in offline/fallback mode using Haversine calculation without throwing errors.
