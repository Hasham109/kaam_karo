## What I Built

### 1. OpenAPI Contract (`contracts/media.yaml`)
- Published contract for Media Service under OpenAPI 3.1.0 (semver 0.1.0).
- Registered in `contracts/README.md`.
- Endpoints defined:
  - `POST /v1/media/upload-session`: Initiates upload session with pre-checks on kind, purpose, MIME type, and expected size/duration. Returns signed upload URL and storage key.
  - `POST /v1/media/upload-session/{id}/finalize`: Verifies actual uploaded size and duration against dynamic limits, marks `FINALIZED`, creates video thumbnail or triggers audio STT transcription.
  - `GET /v1/media/{id}/download-url`: Generates signed download URL with 900s TTL.
  - `GET /v1/media/{id}`: Returns metadata for a specific media object.
  - `DELETE /v1/media/{id}`: Soft-deletes media object (`deletedAt = NOW()`).
  - `POST /v1/media/retention/run`: Runs retention cleanup job with dry-run support.
- Validated by `@kaamkaro/contracts` schema tests (31/31 tests pass).

### 2. S3 Storage Abstraction & Fake Implementation (`storage/`)
- `ObjectStorage` interface defining standard S3 operations (`getSignedUploadUrl`, `getSignedDownloadUrl`, `putObject`, `getObject`, `deleteObject`, `headObject`, `checkHealth`).
- `FakeStorageService` with in-memory map and HMAC-SHA256 signature generation & verification. Rejects expired or tampered signatures (`INFRA-003`, D-001). Zero external AWS/S3 npm dependencies required.

### 3. Video Thumbnail & Audio Transcription Services (`thumbnail/`, `speech-to-text/`)
- `ThumbnailService`: Generates thumbnail JPEG placeholder and stores it via `ObjectStorage`, creating a child `MediaObject` of kind `THUMBNAIL` linked via `thumbnailMediaId` (`MEDIA-005`).
- `FakeSpeechToTextService`: Generates simulated transcriptions for voice notes (`MEDIA-006`). If STT fails, the error is logged and the audio file remains fully playable and finalized without failing the request (BP §76).

### 4. Dynamic Limits & Acceptance Criterion (`media.service.ts`)
- Config keys resolved dynamically via `ConfigService`:
  - `media.max_upload_bytes`: 25 MiB (default: 26,214,400 bytes)
  - `media.video.max_seconds`: 30 seconds
  - `media.audio.max_seconds`: 120 seconds
  - `media.retention_days`: 30 days
- Fails closed with `LIMIT_NOT_CONFIGURED` in non-dev environments when required limits are null or missing.
- **Verbatim Acceptance Criterion:** *"Oversize/overlong media rejected; draft survives failure"* (IMPL §6 T3.2, BP §76).
  When an upload violates size (413) or duration (400) limits during finalization, `MediaObject.uploadStatus` is updated to `FAILED` and an exception is thrown without deleting the database record, allowing client draft requests to preserve their state and retry.

### 5. Data Classification & Security Controls
- `determineSensitivity()`: Automatically tags `VERIFICATION_DOCUMENT` and `PAYMENT_PROOF` as `RESTRICTED` sensitivity (ABUSE-010, BP §29).
- Database constraints enforced in PostgreSQL:
  - `media_object_restricted_purposes`: Rejects restricted purposes if sensitivity is `STANDARD`.
  - `media_object_sizes_not_negative`: Rejects negative bytes or durations.
  - `kk_freeze`: Prevents updating immutable columns (`owner_user_id`, `storage_key`).

### 6. Controller & Module Registration (`media.controller.ts`, `media.module.ts`, `app.module.ts`)
- Registered `MediaModule` in NestJS `AppModule`.
- Exposes REST endpoints with `@Public()` and `AuthGuard`.

## Known Limitations & Upstream Assumptions
- S3 storage uses `FakeStorageService` for local dev/testing (`D-001`). When deploying to production with AWS S3 / Cloudflare R2, implement `AwsS3StorageService` conforming to the `ObjectStorage` interface.
- Audio transcription uses `FakeSpeechToTextService` with Urdu/English sample phrases. In production, connect an external speech-to-text service provider (e.g. OpenAI Whisper or Google Cloud Speech-to-Text).
