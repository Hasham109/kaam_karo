## What I built
**1. OpenAPI Contract** (`contracts/profiles.yaml`, v0.1.0):
- Endpoints for customer & provider profiles, saved addresses, immutable location snapshots, and customer favorites:
  - `GET /v1/profiles/customer/me`: customer profile retrieval.
  - `PATCH /v1/profiles/customer/me`: updates customer display name and preferred language.
  - `GET /v1/profiles/customer/addresses`: list saved addresses (PROF-ADDR-001).
  - `POST /v1/profiles/customer/addresses`: create address (supports HOME, WORK, CUSTOM labels; WGS84 coordinates or manual entry).
  - `PATCH /v1/profiles/customer/addresses/{addressId}`: update address.
  - `DELETE /v1/profiles/customer/addresses/{addressId}`: soft-delete address (sets `deleted_at`; never alters existing booking snapshots).
  - `POST /v1/location/snapshots`: create immutable location snapshot from saved address or direct entry (LOC-GEO-003, LOC-GEO-004).
  - `GET /v1/location/snapshots/{snapshotId}`: retrieve snapshot with role-based masking (PROF-ADDR-004).
  - `GET /v1/profiles/customer/favorites`: list saved favorite providers (PROF-FAV-001).
  - `POST /v1/profiles/customer/favorites`: save favorite provider with optional notes (PROF-FAV-001).
  - `DELETE /v1/profiles/customer/favorites/{providerProfileId}`: remove favorite provider.
  - `GET /v1/profiles/provider/me`: provider profile retrieval for authenticated provider.
  - `PATCH /v1/profiles/provider/me`: update business name, profile photo, and usual team size (ROLE-002, D-004, D-018).
  - `GET /v1/profiles/providers/{providerProfileId}`: public provider profile view.
- Validated via `@kaamkaro/contracts` test suite (`pnpm --filter @kaamkaro/contracts test`). Registered in `contracts/README.md`.

**2. Address Service** (`services/api/src/modules/profiles/address.service.ts`):
- `listAddresses`: retrieves non-deleted saved addresses with PostGIS latitude & longitude (`ST_Y` / `ST_X`).
- `createAddress`: validates city existence, mandates `customLabel` when `labelKind = CUSTOM`, inserts PostGIS geography point if coordinates are provided, or creates manual address with NULL point (PROF-ADDR-003).
- `updateAddress`: validates custom label requirement and updates address fields and coordinates.
- `deleteAddress`: enforces soft-deletion (`deleted_at = NOW()`), ensuring physical rows remain intact and booking snapshots are unaffected (PROF-ADDR-002).

**3. Location Snapshot Service** (`services/api/src/modules/profiles/location-snapshot.service.ts`):
- `createSnapshot`:
  - When copying from saved address: snapshots `addressText`, `areaName`, `cityId`, `placeRef`, PostGIS coordinates, and references `sourceAddressId`. Sets `confirmationStatus = CONFIRMED` and `source = SAVED_ADDRESS` (PROF-ADDR-002, LOC-GEO-003).
  - Direct manual entry / map pin: validates city, sets `confirmationStatus`, saves snapshot (PROF-ADDR-003, LOC-GEO-004).
- `getSnapshotForCaller`: enforces role-based provider masking (PROF-ADDR-004): unaccepted providers on a job see only `areaName` and `cityId`; exact `addressText`, `addressLabel`, `placeRef`, and coordinates are masked to `null`. Accepted providers, customers, and admins see full location data.

**4. Customer & Provider Profile Services** (`customer-profile.service.ts`, `provider-profile.service.ts`):
- Auto-provisions profile record on first access if absent.
- Updates customer profile display name and language (ROLE-001).
- Updates provider profile business name and `usualTeamSize` (ROLE-002, D-004, D-018).
- Exposes public provider profile view displaying business name and usual team size without revealing private contact details.

**5. Favorite Service** (`services/api/src/modules/profiles/favorite.service.ts`):
- Enables customers to bookmark preferred providers for fast rebooking (PROF-FAV-001).
- Upserts favorite with optional private notes.
- Enforces uniqueness via composite key `(customerProfileId, providerProfileId)`.
- Deletes favorite on customer request.
